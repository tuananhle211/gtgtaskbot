# Apexmed Brand Guideline — the facts the UI uses

Source: "Brand Guideline — Hệ thống nhận diện chính thức cho thương hiệu" (GTG, 05/2026, LONGSUHAO).

## Name & meaning
- **APEX** = đỉnh cao, điểm cao nhất; **MED** = Medical → *đỉnh cao của y học và chăm sóc sức khoẻ*.
- **Chữ A**: a mountain / an arrow pointing up — khát vọng vươn lên, dẫn đầu.
- **Dấu "+" xanh nhạt** at the centre of the A: y tế, bệnh viện; "con người và sức khoẻ khách hàng là trọng tâm".
- Brand words: **y tế cao cấp · công nghệ hiện đại · sang trọng tối giản · chuyên nghiệp tin cậy**.
- Closing values: **Sạch · Cao cấp · Đồng bộ · Tin cậy · Chuẩn y khoa**.

## Type (guideline → web stand-in)
- Heading: **Conthrax** medium/bold (mạnh mẽ, hiện đại, công nghệ) → **Exo 2**.
- Heading serif: **Copperplate** (sang trọng) → not used in the app.
- Body: **Jura** light/book/medium (dễ đọc, chuẩn y tế) → **Jura** for labels; dense UI uses Be Vietnam Pro.
- Web/LDP: **UTM Mobifone KT** → **Be Vietnam Pro**.
- Script accent: Motherland Signature / SloopScriptPro — 1–3 words only, never long text.
- Font library (internal): `M:\THIẾT KẾ\KHO CHUNG\LONGSUHAO\library\fonts`.

## Do / Don't
- DO: 2–3 font groups per layout max; body text left-aligned; clear heading/body contrast; script font as a small accent.
- DON'T: script font for long text; too many all-caps fonts; a classic body font as the main font;
  **light blue for small text on a white background**.
- Logo: never stretch, tilt, recolour or add effects; place it on clean, high-contrast backgrounds.
